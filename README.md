# React Native Projects

Personal project by **Thevin2002**.

## Tech stack

TypeScript / React, JavaScript, Node.js / npm, React Native

## How to run

Two React Native apps:

- `projectRN/projectRN` - Expo app (Expo SDK 49, React Native 0.72):
  ```bash
  cd projectRN/projectRN
  npm install
  npx expo start   # scan the QR code with the Expo Go app, or press a for Android
  ```
- `testproject/testproject` - plain React Native 0.72 app (needs Android Studio / an emulator).

Tested: `npm install` succeeds for both. Running on a device needs Expo Go or the Android SDK.
